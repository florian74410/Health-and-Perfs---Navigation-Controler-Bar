## 1 — Installer le bon paquet

Pour Linux Mint XFCE choisissez de préférence le **`.deb`** ; vous trouverez également un bundle Flatpak, un `.run` autonome, des exécutables Windows et des DMG macOS. Tous les liens officiels sont dans [Executable/](../../Executable/README.md). Consultez [Installation](Installation.md) avant d'utiliser un autre format.

## 2 — Configurer la barre

Au premier lancement, le programme demande les paramètres d'affichage. Les valeurs recommandées : **haut de l'écran**, **longueur 100 %**, **épaisseur 72 px**, **opacité des fonds 88 %**. La barre peut se rétracter après **15 s** sans interaction si vous activez cette option.

## 3 — Identifier les actions

| Repère | Fonction |
|---|---|
| 🎛️ Six panneaux | CPU, GPU, RAM, SSD, ventilateurs et réseau |
| 🧩 | **Extensions** ouvre les plugins et les sources GitHub |
| ⚙️ | **Préférences** configure les mesures et l'interface |
| 📂 | **Dossier** ouvre la configuration locale |
| 📖 | **? Wiki** ouvre le présent guide dans le navigateur (v0.3.6+) |
| ⤢ | Déplier/réduire la hauteur ; sans dépasser 150 px |
| ✕ | Quitter (aussi **Ctrl+Q**) |

## 4 — Activer le mode Holo CPU

Ouvrez le Plugin Manager et installez le plugin **CPU Manager / Viewer** compatible depuis le catalogue. Activez-le, puis cliquez sur le module **CPU**. Un panneau séparé **CPU CORE MATRIX** s'ouvre. Il peut être épinglé ou refermé. [Voir Holo CPU](Holo-CPU.md).

## 5 — Raccourcis utiles

**Ctrl+B** est la combinaison par défaut pour afficher/masquer la barre (si le système autorise sa capture). **Ctrl+Q** permet de quitter. Un mécanisme de raccourcis locaux remplace les raccourcis globaux quand ils ne sont pas accessibles.

> 💡 L'absence de mesure est indiquée par **—**. C'est normal sur un matériel qui ne fournit pas la sonde correspondante.
