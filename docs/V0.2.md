# NovaBar — Changelog fonctionnel V0.2 (31-10-2026)

## Livré dans la branche feature/navbar-foundation

- HUD sans cadre global avec tracés PCB électriques, six blocs, navigation à droite, opacité de 0 à 100 %.
- Placement haut/bas/droite, longueur 25–100 % avec alignement, épaisseur, bouton d'agrandissement, rétraction après 15 s par défaut.
- Préférences en cinq onglets : Générale, Affichage, Édition, Extensions, Aide.
- Collecteur read-only : psutil pour charge/fréquence CPU (si fournie par l'OS), température et RPM (si fournis), RAM, disque, réseau ; nvidia-smi en option.
- Polling asynchrone : la lecture nvidia-smi n'interrompt pas le dessin Qt.
- Valeurs manquantes = "—" ; le champ de santé SSD n'est pas estimé artificiellement.
- Drag/déplacement des 6 modules avec persistance de leur ordre.
- Console Shell : liste des scripts locaux d'un dossier choisi, confirmation explicite, journal dans App/Repports/NovaBar.
- API plugin 2 : installation ZIP par extraction validée avec sauvegarde de la version précédente, droits de fichiers non-exécutables et rapport dans App/Repports/Plugins. Les archives API 1 restent compatibles.
- 7 packs indépendants produits par scripts/build_plugins.py : CPU, GPU, CPU Temperature, RAM, Storage, Fans, Network.
- Les boutons de navigation à droite restent visibles ; pas de mini-menu invisible.

## Ce qui n'est pas encore livré

- Le store VPS et son API/catalogue signé ; pas de serveur public présumé.
- Le Theme Manager actif : le design Cyber-Futuriste est intégré au HUD, mais les autres packs thème ne peuvent pas encore être appliqués dynamiquement.
- Overclock, Turbo et écriture des PWM : aucune commande matériel privilégiée par défaut.
- Lectures GPU AMD/Intel sur tous les OS, SMART SSD, détails NVMe génération et tous les ventilateurs au-delà des trois premières lignes : sondes et UI supplémentaires à développer.
- Égalité photographique pixel à pixel avec l'image conceptuelle ; l'interface est vectorielle et responsive.
- Compatibilité Windows 7 : Qt6 n'est pas supporté ; port legacy séparé.
- Overlay Wayland universel pour Bazzite : une intégration layer-shell spécifique serait nécessaire.
- Builds macOS Intel/anciens Mac et signatures notarization : restent à certifier sur les machines concernées.

## Installation et confiance

Les plugins contiennent manifest.json, DEPENDENCY.md, VERSION.md, README.md, install.sh,
Source Code, Scripts, Assets et Profils/Template. L'importateur inspecte l'archive et
n'exécute PAS install.sh, car un fichier ZIP arbitraire peut contenir du code malveillant.
Les dépendances sont annoncées avant validation, mais la mise à jour système n'est pas
automatique. Les permissions de contrôle matériel seront gérées séparément.

Les plugins doivent être ajoutés via **Extensions > Plugin Manager**, puis activés.
Les installations et les profils sont propres à l'utilisateur et ne requièrent
pas un dossier Program Files protégé par administrateur.
