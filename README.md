# CYBER NEXUS HUD — NovaBar

Bar de navigation futuriste PCB Electric Blue, monitoring matériel et écosystème de plugins pour PC.

## Ressources principales

- [Documentation/ROADMAP.md](Documentation/ROADMAP.md) — spécifications des panneaux holographiques, des effets néon réactifs et futures extensions.
- [Plugins/](Plugins/) — les sept archives ZIP téléchargeables ; **CPU Manager/Viewer v2.0.0** déclare CPU CORE MATRIX.
- [Executable/](Executable/) — installateurs existants de NovaBar, version **0.3.1** (sans CPU Holo v2).

## Développement CPU Holo

La version CPU Holo nécessite NovaBar **0.3.2** ou plus récent. Son code source se trouve sur la branche [feature/cyber-nexus-installer-v03](https://github.com/florian74410/Health-and-Perfs---Navigation-Controler-Bar/tree/feature/cyber-nexus-installer-v03) et son intégration dans la [pull request #2](https://github.com/florian74410/Health-and-Perfs---Navigation-Controler-Bar/pull/2).

Installer le ZIP CPU depuis NovaBar > Extensions, puis activer le plugin pour rendre son panneau cliquable. Les capteurs indisponibles affichent « — ». Pas d'overclocking ni d'écriture PWM dans CPU Holo.

**Attention :** la présence du code source v0.3.2 ne met pas automatiquement à niveau les installateurs v0.3.1. Le prochain build doit être validé avant distribution.
